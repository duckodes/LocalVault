# 請使用 GIT LFS 拉取專案才能正常執行 EXE
### 初始化
##### 啟用 Git LFS + 拉取專案
```
git lfs install
git lfs clone https://github.com/duckodes/LocalVault.git
```
##### 停用 Git LFS
```
git lfs uninstall
```

# 密碼庫使用說明

密碼庫是 Windows 上的本機密碼管理程式。網站帳號和密碼存在電腦裡，不會同步到雲端。瀏覽器擴充套件會比對目前網站，列出符合的帳號；選好帳號後才會填入登入欄位，不會替你送出表單。

使用瀏覽器填入功能時，密碼庫 APP 需要保持開啟。可將程式縮到系統匣，但不要選擇結束程式。

## 安裝瀏覽器擴充套件

發佈資料夾裡有 `LocalVault.exe` 和 `BrowserExtension` 資料夾。橋接安裝程式和擴充套件都放在 `BrowserExtension` 裡，安裝後請保留這些檔案。

1. 執行 `BrowserExtension` 資料夾裡的 `install-browser-bridge.cmd`。橋接程式會安裝到目前 Windows 使用者的 AppData，並登記 Chrome、Edge、Brave 和 Firefox 的連線資訊。不需要系統管理員權限。

2. 到瀏覽器的擴充套件頁面載入對應資料夾：

   - **Chrome**：開啟 `chrome://extensions`，啟用「開發人員模式」，按「載入未封裝項目」，選取 `BrowserExtension\Chromium` 資料夾。
   - **Edge**：開啟 `edge://extensions`，啟用「開發人員模式」，按「載入解壓縮」，選取 `BrowserExtension\Chromium` 資料夾。
   - **Brave**：開啟 `brave://extensions`，啟用「開發人員模式」，按「載入未封裝項目」，選取 `BrowserExtension\Chromium` 資料夾。
   - **Firefox**：開啟 `about:debugging#/runtime/this-firefox`，選「此 Firefox」和「載入暫時附加元件」，再選取 `BrowserExtension\Firefox\manifest.json`。暫時附加元件在 Firefox 關閉後會移除，下次使用時要重新載入。長期安裝需要 Mozilla 簽署的附加元件。

瀏覽器會詢問是否允許擴充套件存取網站。允許後，它才能偵測登入欄位並填入資料。載入完成後，重新啟動瀏覽器。

Windows 可能會封鎖尚未簽章的程式。若出現封鎖畫面，請保留 Windows 安全設定。這個版本沒有受信任的程式碼簽章，因此有些電腦可能無法直接執行。

## 建立和解鎖密碼庫

第一次開啟 APP 時，設定至少 12 個字元的主密碼，並再次輸入確認。主密碼遺失後無法重設，密碼庫裡的資料也無法取回。建議使用容易記住、別人不容易猜到的長句。

之後每次開啟 APP，都要輸入主密碼解鎖。開啟背景模式後，按右上角的叉號或最小化，程式會鎖定並縮到系統匣。按 `Ctrl+Alt+P`、雙擊系統匣圖示，或從系統匣選單開啟程式，再輸入主密碼即可。從系統匣選擇「結束程式」會關閉 APP。

## 新增和管理密碼

解鎖後可以新增網站、項目名稱、帳號和密碼，也可以搜尋、修改或刪除資料。新增或修改後，按「儲存」才會把變更寫入密碼庫。使用密碼產生器建立密碼後，也要記得儲存。

在網站的登入欄位點一下，擴充套件會查詢密碼庫中是否有相符的網站帳號。選取帳號後才會填入資料，不會自動登入或送出表單。為了避免密碼送到不安全的網站，只有 HTTPS 網站可以填入密碼，localhost 除外。

密碼庫鎖定時，可以在擴充套件開啟的獨立視窗輸入主密碼，不必把主密碼輸入網站。連續輸錯 5 次後，解鎖會暫停 1 分鐘。

其他常用操作：

- 按 `F5` 可重新載入上次儲存的資料。有尚未儲存的變更時，程式會先詢問是否捨棄。
- 複製密碼後，APP 會在 30 秒後嘗試清除剪貼簿。若期間複製了其他內容，APP 不會覆蓋新內容。Windows 剪貼簿歷程或其他剪貼簿管理程式仍可能保留先前複製的密碼。

## 設定和檔案位置

在設定裡可以更改密碼庫資料夾，也可以開啟或關閉背景模式。預設密碼庫檔案在 `%LOCALAPPDATA%\LocalVault\vault.dat`。更改資料夾時，如果新位置沒有 `vault.dat`，APP 會複製目前的加密檔案過去，原檔不會刪除。

請另外備份 `vault.dat`。備份檔仍有加密，但沒有主密碼就無法開啟；如果主密碼遺失，備份也無法還原。

## 安全性

密碼庫使用 AES-256-GCM 加密。加密金鑰由主密碼透過 PBKDF2-HMAC-SHA256 衍生，迭代 600,000 次。每個密碼庫使用隨機 salt，每次儲存使用新的 nonce。APP 不會把未加密的密碼庫寫入磁碟。

瀏覽器查詢網站帳號時不會取得密碼。只有選取帳號並要求填入時，APP 才會傳回該筆密碼。APP 和橋接程式透過限於目前 Windows 使用者的本機 Named Pipe 傳送資料，不經網路，也不會把主密碼或網站密碼存進擴充套件的瀏覽器儲存區。

加密不能保證程式絕對不會被破解或反編譯，也無法防止受感染的電腦、鍵盤側錄或其他有權限的程式讀取執行中的記憶體。請保持 Windows 更新，不要在不信任的電腦上解鎖密碼庫，並妥善保管主密碼。
