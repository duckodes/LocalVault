# 請使用 GIT LFS 拉取專案才能正常執行 EXE
### 初始化
##### 啟用 Git LFS + 拉取專案
```
git lfs install
git lfs clone https://github.com/duckodes/LocalVault.git
```
##### 停用 Git LFS
```
git lfs uninstall
```

# LocalVault 密碼庫說明

Windows 本機密碼管理程式，不提供雲端同步。以下比較 `main` 與 `tpm` 分支；目前專案程式及新增功能以 `tpm` 分支為準。

## 分支比較

| 項目 | `main` | `tpm` |
|---|---|---|
| **加密** | AES-256-GCM；主密碼經 PBKDF2 衍生 AES 金鑰。 | AES-256-GCM；隨機 AES 金鑰由 TPM RSA-2048 金鑰封裝，主密碼經 PBKDF2-HMAC-SHA256（600,000 次）保護封裝資料。TPM 私鑰不可匯出。 |
| **解鎖與換機** | 輸入主密碼解鎖；可將 `vault.dat` 移至其他電腦。 | 需要主密碼及建立密碼庫時的 TPM；單獨備份無法換機解鎖。 |
| **優點** | 不依賴特定電腦或 TPM，較容易移轉。 | TPM 提供額外硬體金鑰保護。 |
| **缺點** | 安全性較依賴主密碼強度。 | TPM 重設或遺失可能使資料無法復原。 |
| **舊庫格式** | 使用 `main` 格式。 | 可解鎖舊 `main` 密碼庫；成功後會遷移至 TPM 格式。 |
| **瀏覽器帳號提示** | 依 `main` 原有流程提供帳號建議；查詢時可能先將候選帳號傳到擴充套件。沒有 `tpm` 的選擇前不傳資料設計。 | 聚焦登入欄位只顯示提示，不先傳帳號清單。按提示後由主程式顯示選擇頁；使用者選定後才傳送該筆帳密。無匹配時也會顯示提示。 |
| **網站比對與填入** | 不具 `tpm` 的完整來源比對及 HTTPS／localhost 填入限制。 | 以完整來源比對；僅 HTTPS 或 localhost 可填密碼，不會自動送出表單。 |
| **主密碼輸入** | 依 `main` 原有解鎖流程。 | 只在主程式輸入，不傳給擴充套件。 |
| **瀏覽器通訊** | 依 `main` 原有橋接方式。 | Native Messaging 連接橋接程式，再以目前 Windows 使用者限定的 Named Pipe 連接 APP；檢查程序路徑及瀏覽器祖先僅屬額外防護，不是強身分驗證。 |
| **鎖定行為** | 背景模式開啟時，按 X 或最小化會鎖定並縮至系統匣。 | 背景模式下按 X 會鎖定並縮至系統匣；最小化後預設 5 秒自動鎖定，Windows 工作階段鎖定時也會鎖庫。瀏覽器選定資料後會鎖定並縮至系統匣。 |
| **瀏覽器觸發時密碼庫鎖定** | 可在擴充套件的獨立視窗輸入主密碼；連續錯誤 5 次暫停 1 分鐘。 | 主密碼在主程式輸入，不經擴充套件傳送；主程式顯示網站相符帳號的選擇頁。 |
| **畫面擷取** | 不包含 `tpm` 的預設畫面擷取排除設定。 | 預設啟用 `SetWindowDisplayAffinity` 排除主視窗；不是安全邊界，不能防止所有擷取或記憶體讀取。 |
| **設定重置** | 依 `main` 分支原有設定。 | 「重置預設」還原背景模式、預設資料夾、5 秒鎖定倒數及啟用畫面擷取排除；儲存後才套用。 |
| **瀏覽器安裝** | 執行 `BrowserExtension\install-browser-bridge.cmd`，再載入 `BrowserExtension\Chromium` 或 Firefox manifest；Firefox 暫時附加元件重啟瀏覽器後需重載。 | 同左；擴充套件需獲准存取網站。 |
| **主密碼** | 至少 12 個字元；忘記後無法重設。 | 同左；每次重新啟動需解鎖。 |
| **密碼管理** | 可新增、搜尋、修改、刪除；修改後儲存，`F5` 載入上次儲存內容。 | 同左。 |
| **剪貼簿** | 複製密碼後 30 秒嘗試清除；剪貼簿歷程或其他管理程式仍可能留存。 | 同左。 |
| **密碼庫位置** | 預設 `%LOCALAPPDATA%\LocalVault\vault.dat`；設定可更改資料夾，新位置若無密碼庫會複製加密檔案並保留原檔。 | 同左；備份還原另需原 TPM。 |
| **執行期間風險** | 程式會清除部分暫存位元組，但無法保證抹除 .NET 字串或物件；惡意程式仍可能讀取記憶體、鍵盤輸入或畫面。 | 同左；TPM 不能防護已遭入侵的 Windows 工作階段。 |
| **其他安全提醒** | 瀏覽器及網頁可能讀取已填入的密碼；擴充套件需廣泛網站權限。請確認網站、只安裝可信任的擴充套件並保持 Windows 更新。 | 同左；畫面擷取排除不是安全邊界，不能防止不支援的擷取方式、記憶體讀取或相機拍攝。 |
